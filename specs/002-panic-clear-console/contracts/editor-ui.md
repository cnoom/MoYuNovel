# Contract: 编辑器用户入口（UI/交互契约）——002 增量

**Assembly**: `CNoom.MoYuNovel.Editor` | 基线见
`specs/001-console-novel-log/contracts/editor-ui.md`；本文只记录 002 的增量。
命名原则不变：中性低调，统一产品名 **Log Reader**。

## 菜单 / 快捷键（无变化）

入口清单与 001 契约一致；急停行为按下方「急停后行为」增量更新。

## 急停后行为（增量，FR-001/FR-003/FR-004，FR-002 修订）

```text
触发任一急停入口（快捷键 / Esc 尽力层 / 菜单 Panic Stop）
  1. 立即停止全部输出（≤1s 落停，SC-002，001 契约不变）
  2. 进度落盘（断点续读语义不变）
  3. 若「急停时清空 Console」开关为开（默认）：
     选择性移除本插件条目——统一标记 token（如 "[nv]"）的连载行/完结提示、
     "[LogReader]" 前缀系统日志；业务日志内容与相对顺序原样保留。
     清理不可用或 Console 处于过滤态时静默跳过（绝不回退全量清空），
     不弹窗、不写任何日志
```

普通 Stop / Pause / 完结提示 / 播放模式切换静默停机：**不执行第 3 步**，
Console 内容原样保留。

## 设置窗口（增量：「急停快捷键」区块更名为急停区块）

标题仍为 **Log Reader**；急停区块布局更新为：

| 控件 | 行为 | 对应 |
|------|------|------|
| 主急停键 + 当前键位 | 「改键…」进入录制态；「恢复默认」回 `Ctrl+Shift+F12` | 001 FR-002（已实现） |
| **急停时清空 Console**（Toggle） | 默认勾选；变更即写 settings.json；取消勾选后急停只停不清 | 002 FR-007 |
| 说明行 | 保留「Esc 备用急停」提示；开关关闭时追加「当前急停仅停止输出」 | 002 FR-007 |

开关为只读 Profile 等场景不影响本 Toggle（改键按钮的禁用逻辑独立）。
