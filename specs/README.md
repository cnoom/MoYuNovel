# specs

本仓所有工作走 spec-kit 流程（铁律：先在 `specs/NNN-<feature>/` 下建 feature 目录，再动代码）。

## 流程

1. `/speckit-constitution` —— 建立或修订项目宪法（`.specify/memory/constitution.md`）
2. `/speckit-specify` —— 从自然语言需求生成 feature 规格（spec.md）
3. `/speckit-clarify` → `/speckit-plan` → `/speckit-tasks` → `/speckit-implement`

命名自 `001-` 顺延。首个 feature：Console 日志连载小说（摸鱼核心玩法）。
