# Feature Specification: Console 日志连载小说（摸鱼核心玩法）

**Feature Branch**: `001-console-novel-log`

**Created**: 2026-10-10

**Status**: Draft

**Input**: User description: "让 Unity Console 以正常业务日志的口吻持续输出小说正文内容，供开发者摸鱼阅读；支持开始/暂停/停止、输出节奏控制、伪装模板、进度记忆断点续读、内置示例小说与自定义文本导入"

## Clarifications

### Session 2026-10-10

- Q: 导入的 txt 小说按什么规则划分章节？ → A: 正则识别常见章节标题（第X章/节/回、Chapter N 等），无标记视为单章；进度按全局行号，章节仅作显示分组
- Q: 书架、输出间隔、伪装预设、清除进度这些配置功能以什么界面形态提供？ → A: 独立 EditorWindow 集中管理（书架、进度、间隔、伪装预设、清除入口）；菜单/快捷键仅负责启停与急停
- Q: 输出间隔的下限与默认值设为多少？ → A: 下限 0.2 秒、默认 1 秒；下限仅防 Console 渲染卡顿，阅读节奏完全由用户自调
- Q: 内置的示例小说用什么内容来源？ → A: 公有领域章回小说节选（《西游记》前几回），版权零风险且天然带章节结构
- Q: 快捷键急停的默认键位用哪个？ → A: 默认 Esc，可在设置窗口自定义键位（Esc 与编辑器固有行为的兼容性见边界用例）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 摸鱼连载输出 (Priority: P1)

开发者（用户）在编辑器里开启「摸鱼模式」后，Console 窗口以正常业务日志的观感、
按可调节奏逐行输出小说正文；老板路过时看到的只是一串"日志"。

**Why this priority**: 持续连载输出是本插件存在的唯一理由，没有它其余一切无意义。

**Independent Test**: 仅实现本故事即可交付 MVP——开启后 Console 连续出现带伪装
前缀的小说行，间隔可调。

**Acceptance Scenarios**:

1. **Given** 插件已安装且未开启, **When** 用户通过菜单开启摸鱼模式, **Then**
   Console 开始按配置的间隔逐行输出当前小说正文。
2. **Given** 摸鱼模式输出中, **When** 用户调整输出间隔, **Then** 后续行按新间隔
   输出，且间隔不得低于下限。
3. **Given** 摸鱼模式输出中, **When** 用户暂停后恢复, **Then** 从暂停位置的
   下一行继续，不跳行、不重复。
4. **Given** 某段落远超单行长度, **When** 输出到该段, **Then** 自动切分为多行
   输出，每行保持"日志行"观感。

---

### User Story 2 - 安全停止与默认静默 (Priority: P1)

用户能随时一键终止全部输出（含快捷键急停），且重启编辑器后插件保持静默，
不会一打开 Unity 就开始"自high"暴露摸鱼。

**Why this priority**: 摸鱼的安全底线——被发现的代价远大于少读几章；与宪法
原则 II 直接对应，与输出能力同等重要。

**Independent Test**: 可独立验证——开启输出后急停，最后一条输出在 1 秒内落停；
重启编辑器后无任何输出，直到用户再次手动开启。

**Acceptance Scenarios**:

1. **Given** 摸鱼模式输出中, **When** 用户触发急停（菜单或快捷键）, **Then**
   立即停止输出，无需等当前段落输出完。
2. **Given** 摸鱼模式输出中且编辑器被重启, **When** 编辑器重新打开, **Then**
   不自动恢复输出（默认静默），但阅读进度仍在。
3. **Given** 编辑器进入/退出播放模式（含域重载）, **When** 播放模式结束回到
   编辑状态, **Then** 插件保持静默，不自动恢复输出。

---

### User Story 3 - 断点续读 (Priority: P2)

用户昨天下班前读到第三章某行，今天打开编辑器开启摸鱼模式，从那一行继续，
进度不清零；也提供"从头再读/清除进度"的入口。

**Why this priority**: 没有进度记忆的连载体验是残缺的，但不阻塞 MVP（可从
第一章重读）。

**Independent Test**: 读到任意位置后重启编辑器再开启，输出从上次位置的下一行
开始；清除进度后从第一章第一行开始。

**Acceptance Scenarios**:

1. **Given** 已读到某章某行, **When** 重启编辑器并再次开启摸鱼模式, **Then**
   从上次停止行的下一行继续。
2. **Given** 存在历史进度, **When** 用户清除进度, **Then** 下次开启从小说
   开头输出，且进度记录被清空。

---

### User Story 4 - 内容来源：内置示例与自定义导入 (Priority: P2)

用户开箱即读（内置无版权风险的示例小说），也能导入自己的本地 txt 小说建
私人书架。

**Why this priority**: 没有内容就没有可读之物；内置示例保证零配置可用，导入
保证长期可用性。

**Independent Test**: 安装后不开任何配置即可开启并读到内置小说；导入一本
txt 后可切换到它并开始输出。

**Acceptance Scenarios**:

1. **Given** 全新安装, **When** 用户开启摸鱼模式, **Then** 直接输出内置示例
   小说，无需任何前置配置。
2. **Given** 用户选择本地 .txt 文件, **When** 完成导入, **Then** 该小说出现在
   可选列表中并可立即开始阅读。
3. **Given** 导入的 txt 为 GBK 等非 UTF-8 编码, **When** 导入, **Then** 尽力
   自动探测编码正确显示，无法识别时给出明确提示且不影响已有内容。

---

### User Story 5 - 伪装定制与日志隔离 (Priority: P3)

用户可切换/自定义伪装样式（让输出看起来像自己项目的日志），且摸鱼输出与
正常日志可一键区分过滤，不干扰真实排错。

**Why this priority**: 锦上添花但显著提升"安全性"与日常可用性；默认预设已可
用，故列 P3。

**Independent Test**: 切换不同伪装预设后新输出行样式随之变化；用统一标记过滤
后 Console 只剩正常业务日志。

**Acceptance Scenarios**:

1. **Given** 摸鱼模式输出中, **When** 用户切换伪装预设（如"网络模块"/"UI
   模块"样式）, **Then** 后续输出行采用新样式。
2. **Given** Console 混有业务日志与摸鱼输出, **When** 用户按统一标记过滤,
   **Then** 摸鱼输出可被完全隐藏或完全单独查看。

---

### Edge Cases

- 导入的文本为空文件或无有效正文时如何处理？（拒绝导入并提示，不影响现有书架）
- 读完小说最后一行时会发生什么？（停止输出并提示"已完结"，不自动循环）
- 输出间隔被设置为极小值或非法值时？（钳制到下限，配置界面同步显示钳制后
  的生效值）
- 单章超长（数万行）时进度与切行是否正确？（逐行推进不受章节长度影响，
  不整章载入内存做无谓拷贝）
- 播放模式中 Console 有真实报错时，摸鱼输出是否会淹没错误？（输出节奏有
  下限、支持一键过滤/急停，保证真实错误可读）
- Esc 在编辑器中有大量固有行为（取消重命名、关闭弹窗、取消工具等）：急停
  拦截 MUST NOT 破坏这些原生行为；若全局拦截 Esc 在技术上不可行，MUST
  回退为一个可自定义的普通组合键默认值并在文档中说明。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 提供摸鱼模式的开启、暂停、恢复、停止四种控制，并
  在菜单暴露全部入口。
- **FR-002**: 系统 MUST 提供快捷键急停，触发后 1 秒内停止一切待输出内容；
  快捷键默认 Esc，MUST 可在设置窗口中自定义。
- **FR-003**: 系统 MUST 按用户可配置的间隔逐行输出小说正文；间隔默认 1 秒、
  下限 0.2 秒，非法或越界配置值 MUST 被钳制到下限。
- **FR-004**: 每一行输出 MUST 携带统一的可过滤标记，且默认带伪装前缀，观感
  与常见业务日志一致。
- **FR-005**: 编辑器重启后系统 MUST NOT 自动恢复输出；用户未显式开启前保持
  完全静默。
- **FR-006**: 播放模式切换与域重载后系统 MUST NOT 自动恢复输出。
- **FR-007**: 阅读进度（当前作品与行位置）MUST 持久化，重启后可从断点继续；
  系统 MUST 提供清除全部进度的入口。
- **FR-008**: 系统 MUST 内置至少一篇无版权风险的示例小说（公有领域章回小说
  节选，如《西游记》前几回），开箱即可阅读。
- **FR-009**: 系统 MUST 支持导入本地纯文本小说（.txt），导入内容仅保存在
  本机；对非 UTF-8 编码 MUST 尽力自动探测，失败时明确提示。
- **FR-010**: 系统 MUST NOT 访问网络。
- **FR-011**: 摸鱼输出 MUST NOT 出现在任何玩家构建产物或真机日志中。
- **FR-012**: 超长段落 MUST 自动切分为多行，单行输出长度有上限。
- **FR-013**: 伪装样式 MUST 可配置，且 MUST 内置不少于 2 套预设。
- **FR-014**: 输出连载到小说结尾时系统 MUST 停止输出并提示已完结，MUST NOT
  自动循环。
- **FR-015**: 摸鱼输出运行期间编辑器 MUST 保持可交互，MUST NOT 出现可感知
  卡顿。
- **FR-016**: 系统 MUST 提供独立的设置窗口（EditorWindow），集中承载书架
  管理（导入与切换作品）、阅读进度展示与清除、输出间隔配置、伪装预设
  选择；启停与急停入口保留在菜单与快捷键中。

### Key Entities *(include if feature involves data)*

- **小说（Novel）**: 一部可读作品；含标题与正文（章/行结构），来源为内置或
  用户导入。章节由常见标题正则（第X章/节/回、Chapter N 等）自动识别，
  无任何标记的文本视为单章。
- **阅读进度（ReadingProgress）**: 某部小说读到哪一行；含所属作品、行位置
  （全局行号，与章节识别无关）、更新时间，可清除。
- **输出设置（OutputSettings）: 间隔、当前伪装预设、启停状态等用户偏好；
  持久化且重启后默认静默。
- **伪装预设（DisguisePreset）**: 一套输出行外观规则（前缀、格式、统一过滤
  标记的组合）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 开启摸鱼模式后 10 秒内，Console 按配置间隔连续输出正文行，
  期间编辑器无可感知卡顿。
- **SC-002**: 从触发急停到最后一行输出落停不超过 1 秒。
- **SC-003**: 重启编辑器后再次开启，续读位置与上次停止位置偏差为 0 行。
- **SC-004**: 导入 1MB 级别 txt 完成解析并开始阅读不超过 5 秒。
- **SC-005**: 通过统一标记过滤，摸鱼输出与正常业务日志可 100% 区分（漏标
  记行数为 0）。
- **SC-006**: 玩家构建产物与真机日志中的小说输出行数为 0。

## Assumptions

- 使用场景为桌面 Unity 编辑器（以 Windows 为主）；播放模式下 Console 依然
  可用，摸鱼输出在播放模式中默认继续（用户可暂停）。
- v1 仅支持纯文本 .txt（UTF-8 优先、尽力探测 GBK）；EPUB/MOBI 等格式与在线
  书源不在 v1 范围。
- 默认伪装样式模仿常见业务日志（模块前缀 + 正文）；预设只需"像日志"，
  不追求逐项目定制。
- 读完即停在结尾并提示，不自动循环（重复阅读由用户清除进度后重新开始）。
- 单人单机使用，无多用户、云同步、账号体系。
- 章节仅作显示分组，阅读进度与断点续读一律以全局行号为准。
- 所有正文与进度数据仅存于本机编辑器偏好/本地文件，无任何上报。
