# Contract: 编辑器用户入口（UI/交互契约）

**Assembly**: `CNoom.MoYuNovel.Editor` | 面向使用者的全部可见入口。
命名原则：**中性低调**——任何用户可见文案不出现「摸鱼/Novel 摸鱼」等暴露性
词汇（宪法 III 伪装隔离的延伸），统一产品名为 **Log Reader**。

## 菜单（FR-001/FR-002/FR-016）

```text
Tools/Log Reader/
├── Start          # 开始连载（= Idle→Running，从当前进度续读）
├── Pause          # 暂停
├── Resume         # 恢复（从暂停位置下一行，不跳行不重复）
├── Stop           # 停止（回 Idle，进度已保存）
├── Panic Stop     # 急停（与快捷键等价：立即清空待输出）
└── Settings...    # 打开设置窗口
```

菜单项状态与引擎状态机同步：Running 时 Start/Pause 可用性正确翻转；
菜单勾选号（✓）反映 Running/Paused。

## 快捷键（FR-002，双层——见 research.md R1）

| 层 | 键 | 机制 | 说明 |
|----|----|------|------|
| 主急停键 | `Ctrl+Shift+F12`（默认） | ShortcutManager 官方注册 | 用户可在 Unity Shortcuts 窗口或设置窗口改键 |
| Esc 尽力拦截 | `Esc` | 输出运行中反射挂接全局事件 | 编辑器先行消费或反射失败时静默降级，主键兜底 |

触发后行为：立即停调度+清空待输出，Console 最后一条输出 ≤1s 落停
（SC-002）。

## 设置窗口（FR-016，独立 EditorWindow）

标题 **Log Reader**，单窗口集中：

| 区块 | 内容 | 对应 |
|------|------|------|
| 书架 | 作品列表（标题/来源/进度%）；Import 按钮选 .txt；点击切换当前作品 | FR-009、US4 |
| 进度 | 当前作品 章节+行位置 显示；「从头再读」（清本书进度）；「清除全部进度与配置」 | FR-007、US3 |
| 节奏 | 间隔滑条+输入框（0.2–3600s），显示钳制后生效值 | FR-003 |
| 伪装 | 预设下拉（≥2 内置）；统一标记输入（默认 nv，≤8 字符） | FR-013/FR-004 |

导入对话框契约：编码探测失败 → 明确提示「检测到非 UTF-8 文本且无法解码，
请转存 UTF-8 后重试」，书架不变化（FR-009 边界）。

## Console 输出形态（FR-004/US1/US5）

- 每行 = `伪装前缀 + 统一标记 + 正文`，如 `[Net][nv] 正文……`；
- LogType 固定 `Log`（不污染 Warning/Error 视觉）；
- 读完最后一行 → 输出一条完结提示行后进入 Finished，不自动循环（FR-014）；
- 重启编辑器/退出播放模式 → 无任何输出，直到用户显式 Start（FR-005/006）。
